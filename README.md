# Backend_MFC
Бекенд сервис, хранящий сведения о количестве нажатий на кнопки чат бота и ранжирующий их по популярности нажатий. 

Бизнес задача: В чат-боте МФЦ имеется около 150 кнопок с тематиками услуг. Необходимо, чтобы в топе списка находилось 15 самых популярных услуг.

В качестве хранилища используется база данных PostgreSQL, для обработки SQL запросов к БД - `Python бекенд FastAPI`.
Сервис запускает на хосте контейнер PostgreSQL 16.2 с таблицей `table_mfc_2`, а так же контейнер `Python бекенда FastAPI`, запущенного через веб-сервер `uvicorn`.

Для запуска и сборки контейнеров использовать команду:
```
docker compose up --build
```

GET запрос к сервису: http://localhost:8000/session_get

POST запрос к сервису: http://localhost:8000/session_create
